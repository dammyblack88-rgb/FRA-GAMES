# Project Boundaries and Naming

## Current game-development workstream

- **NEXT WORLD** is the original connected-world game universe and player-facing game identity.
- **SimeonJr Studios** is the studio.
- **FRA GAMES** is the existing GitHub repository/workspace currently carrying the NEXT WORLD gameplay foundation.

The current repository contains NEXT WORLD gameplay rules and Unreal Engine source scaffolding. Do not rename the universe to FRA GAMES or invent a competing LagosLife title.

## Separate FRA GAMES platform concept

Earlier planning also described FRA GAMES as a free online/offline games platform: a library of independently licensed games with discovery/search, categories, game pages, favourites/recently played, mobile/fullscreen support, guest access and PWA/offline capabilities.

That games-library concept is a separate product from NEXT WORLD. It is not the same thing as NEXT WORLD's connected game runtime, and the repository's current game-foundation code does not mean that the public game-library platform has been completed.

If both products are developed, keep their product identities, roadmaps, user experiences and legal obligations distinct. Never present a catalogue of unrelated games as the NEXT WORLD universe.

## NEXT WORLD identity and world rules

- One connected identity, life history, progression and persistent world.
- Multiple careers and experiences share the same player identity.
- Lagos first, then expand regionally and internationally.
- Player-generated content is structured, permissioned and moderated.
- Original IP only; no unauthorised copying of commercial games.
- Reuse open-source projects only after licence, dependency, engine-version, security and performance review.

## Repository safety

Continue from the existing GitHub repository and preserve the current code and history. Do not perform destructive rebuilds, wholesale game imports or licence-blind merges. No paid service, GPU, API, asset, subscription or upgrade without explicit approval.
